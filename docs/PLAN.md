# 分形树枝：规划

## 范围

第一版：分区的创建、移动、缩放和锁定，多标签，图标和列表视图，排序，拖入拖出，系统右键菜单，
重命名，框选，双击空白处隐藏或显示图标，按扩展名一键整理，托盘菜单，开机自启，布局导入导出，
屏幕变化和资源管理器重启后自动恢复。

不做：壁纸、搜索、小组件、AI 面板、待办、账号、更新推送、广告和统计。

已定默认：自用；新文件进底层“桌面”区，需要时一键整理；技术栈 Rust + windows-rs + Direct2D/DirectWrite。

## 原则

- 不移动、不改名、不改属性：分类只记录归属，卸载后桌面文件原样。
- 布局是可读的开放 JSON，路径用 `%DESKTOP%`、`%PUBLIC_DESKTOP%` 变量，原子写入并保留备份。
- 不轮询：只在文件变化或用户操作时工作，空闲 CPU 接近 0。
- 失败时退回原生桌面，绝不能让用户的图标“消失”。

## 阶段与验收

| 阶段 | 内容 | 通过标准 |
|---|---|---|
| 0 技术验证 | 透明分区挂到桌面层 | 与 Wallpaper Engine 共存；经受 Win+D、重启资源管理器和切换缩放 |
| 1 导入器 | 小智配置转 `layout.json` | 374 项全部对上，不写入小智目录 |
| 2 只读显示 | 按布局画出全部分区和图标 | 位置与现在一致，首屏小于 150 ms |
| 3 交互 | 拖放、右键、重命名、标签 | 日常操作能完全替代 |
| 4 稳定性 | 守护、自启、异常场景 | 强杀能恢复，连续运行 72 小时内存不持续增长 |
| 5 切换 | 关闭小智自启，试用 | 试用满意后由用户决定是否卸载 |

目标值：空闲私有内存不超过 40 MB（不含显存表面），空闲 CPU 接近 0，安装后小于 10 MB。

进度（2026-11-04）：第 0～2 阶段完成；第 3、4 阶段代码已写，真实鼠标操作和 72 小时运行待验证；第 5 阶段待用户决定关闭小智自启。

已加入（用户反馈后）：桌面空白处右键新建分区（自有菜单项并入系统桌面菜单）、可递归的子分区、桌面框选、分区背景深浅可调。

分发限制：安装包未做代码签名；只支持 DefView 直属 Progman 的桌面结构（Windows 11 24H2 起），旧结构上拒绝安装；只在主显示器上显示分区和图标。

暂未实现：方向键移动选中、列表按时间分组显示、搜索、皮肤、把子分区拖到别的分区下。

## 已知事实（本机，小智 4.0.7.16）

- 桌面窗口树：`Progman` > `SHELLDLL_DefView`（`WS_EX_LAYERED`，LWA_ALPHA 255）> `SysListView32`；
  动态壁纸在 `Progman` > `WorkerW`。
- 小智主窗口 `XZDesktopWnd` 是 `SHELLDLL_DefView` 的子窗口，全屏，自身不是分层窗口，使用 D2D/D3D11，未加载 DirectComposition。
- 数据位于 `%LOCALAPPDATA%\XZDesktop`：`area.dat`（分区）、`vgroup.dat`（组和图标）、`config.json`（设置）。
  格式为 Base64 的 14 字节头，加上 Base64 的 JSON 与 1024 字节循环密钥流异或的结果。
